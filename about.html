About This Project

How Aerial Perspectives was designed and built — from information architecture to responsive code.

🎯 Project Goals

Aerial Perspectives is a multi-page, fully responsive portfolio website originally developed for CCT360: Web Design & Development at the University of Toronto Mississauga. It showcases original drone photography from China, Iceland, and Hawaii — using aerial imagery to build visual narratives of cities, coastlines, and natural landscapes.

The project had two goals: (1) demonstrate front-end proficiency with Bootstrap 5 components, responsive layouts, and interactive UI; and (2) present a coherent visual identity that keeps the photography as the hero while supporting intuitive navigation.

🗺️ Information Architecture

The site is organized in four levels. Level 1 is the global navigation: Home, Portfolio, Flight Log, Resume, Contact. Level 2 defines page-level sections (hero video, carousel, portfolio categories, flight-log tables, resume blocks, contact form). Level 3 holds individual content units — each photograph with its title, description, and shooting metadata. Level 4 covers detail and associative relationships, e.g. the home carousel linking directly into portfolio categories, and thematic bridges such as Urban ↔ City Landmarks.

🎨 Visual Design

A restrained palette — white, dark gray, and a single high-contrast accent blue — keeps the drone imagery as the focal point. A two-font sans-serif system (bold headings, light body) supports scanability and readability, with spacing tuned for WCAG-oriented legibility. Cards use soft corners, balanced padding, and minimal shadows so no element competes with the photography.

🧩 Bootstrap Components

  • Carousel — featured aerial moments on Home, with auto-slide and manual controls.
  • Modal — enlarged photo viewing and the "About this project" dialog, dimming the background to focus attention.
  • Dropdown — portfolio categories grouped under one nav item to keep global navigation clean.
  • Tooltips — micro-explanations on thematic tags without cluttering the layout.
  • Forms & Tables — an accessible contact form and a structured flight-log table for comparing dates, locations, and equipment.

♿ Accessibility (WCAG POUR)

  • Perceivable — meaningful alt text on every image; hero video muted with aria-label.
  • Operable — full keyboard support: tab order, dropdowns, focus outlines, carousel and modal controls.
  • Understandable — consistent layouts, predictable navigation, explicitly labeled form fields.
  • Robust — semantic HTML (header, nav, main, section) plus ARIA attributes on interactive components.

📱 Responsive Design

Three breakpoints adapt the experience:

  • Desktop — three-column card grid, fully expanded navigation.
  • Tablet — grid reflows to two columns (.col-md-6); nav collapses into a hamburger menu.
  • Mobile — single-column layout, full-width cards with touch-friendly targets, minimal header chrome.

Fluid images (.img-fluid) and Bootstrap's grid keep hierarchy consistent without separate markup per device.
