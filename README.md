# Aerial Perspectives

Drone photography portfolio — original aerial shots from China, Iceland, and Hawaii.

🌐 **Live site:** https://jianghai590-maker.github.io/aerial-perspectives/

A multi-page, fully responsive portfolio website built with Bootstrap 5, originally developed for CCT360: Web Design & Development at the University of Toronto Mississauga.

## Pages

- **Home** — hero drone video, featured photo carousel, photography focus & skills
- **Portfolio** — themed collections: Urban Nightscapes, Coastlines, Mountains & Glaciers
- **Flight Log** — structured flight records (date, location, equipment)
- **Resume** — education, skills, experience
- **About** — design process: IA, visual design, Bootstrap components, accessibility, responsive strategy
- **Contact** — accessible contact form

## Tech

- Bootstrap 5.3 (CDN), semantic HTML, vanilla JS
- WCAG-oriented accessibility (POUR principles)
- Responsive across desktop / tablet / mobile breakpoints
- All photos and videos are original work by Hai Jiang
